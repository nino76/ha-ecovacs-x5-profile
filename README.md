# Ecovacs X5 Omni Profile Fix

Custom Home Assistant integration based on the official Ecovacs integration.

## Purpose

Maps the cloud hardware class `4jd37g` to the `mxse7w` hardware profile when retrieving static device capabilities.

All other hardware classes retain their original behavior.

## Installation

Add this repository as a custom repository in HACS (Integration category), then install **Ecovacs X5 Omni Profile Fix**.

Restart Home Assistant after installation.
